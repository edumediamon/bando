# 공정 설명과 3D 시각 안내

상태: 요구사항 정리 및 표현 방식 확인 중. 앱 코드는 아직 변경하지 않았다.

## 요청에서 확인한 범위

- 8개 공정의 설명란에서 현재 진행 중인 부분을 쉽게 알아볼 수 있게 강조한다.
- 색상으로 어떤 부분을 설명하는지 구별한다.
- 이동 방향을 이해하는 데 필요한 화살표를 추가한다. 필요한 곳에는 곡선 이동도 표현한다.
- 외부 API가 필요한 경우 GitHub에서 확인한 자료를 기준으로 도입한다.

## 현재 구현에서 확인한 사실

- 설명은 공정별로 세 개의 세부 단계로 구성되어 있다.
- 현재 세부 단계 표시는 진행률을 삼등분하고, 지나간 단계까지 누적해서 활성화한다.
- 모델의 변화 시점은 삼등분한 설명과 일치하지 않는다. 예를 들어 증착·이온주입의 전환은 50%, 패키징의 와이어 연결과 성형은 약 32%와 72%에 시작한다.
- 현재 WebGL 메시와 튜브 기능으로 직선·곡선 화살표를 구현할 수 있다. 이 요청을 위해 외부 API나 새 라이브러리를 추가할 필요는 없다.

## 제안하는 동작 — 사용자 확인 대기

1. 현재 세부 단계 하나에 배경·테두리·굵은 글씨를 적용하고 설명 문장의 핵심 구절도 강조한다. 대응하는 3D 영역과 화살표에 같은 강조색을 사용한다. 완료한 단계는 체크 표시로 구분하고, 대기 중인 단계는 차분하게 표시한다.
2. 설명과 모델에 공통으로 사용하는 세부 단계 경계를 정의한다. 실제로 여러 작업이 동시에 일어나는 것처럼 보이는 기존 애니메이션도 설명 순서에 맞게 조정한다.
3. ‘방향키’는 이동 방향을 나타내는 화살표로 해석한다. 가스 유입·배출과 회전은 곡선, 빛과 이온의 조사 방향은 직선 등 표현 대상에 맞춘다. 물리적 흐름과 학습용 이동 안내의 의미를 구분해서 표시한다.
4. 화살표 이동은 공정 진행률에 연결한다. 일시정지하면 멈추고, 진행 막대를 앞뒤로 움직이면 설명·강조 영역·화살표 위치가 함께 바뀐다. 웨이퍼 뷰와 단면 뷰 모두 적용한다.

## 검증 범위

- 각 세부 단계의 시작·중간·끝에서 설명과 강조 대상이 일치하는지 검사한다.
- 완료 상태와 현재 상태를 구별하고, 색 외에도 텍스트·상태 표시를 제공한다.
- 곡선의 접선 방향과 화살촉, 중간 진행률의 유한한 모델 좌표를 검사한다.
- 재생·일시정지·되감기·공정 전환과 두 보기의 동기화를 검사한다.
- JavaScript 수정 후 `npm test`를 실행한다. 브라우저 연결이 가능하면 실제 렌더링도 확인한다.
