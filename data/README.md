# FAB LAB

반도체 8대 공정을 둘러보는 한국어 인터랙티브 3D 웹 앱입니다. 외부 라이브러리·CDN·API 키 없이 브라우저의 WebGL로 모델을 그립니다.

## 실행

Node.js 18 이상에서:

```powershell
cd D:\dev\data
npm run dev
```

브라우저에서 <http://127.0.0.1:4173>을 엽니다. 포트가 사용 중이면 `$env:PORT=4174`로 바꿀 수 있습니다. ES 모듈을 사용하므로 HTML 파일을 직접 여는 대신 로컬 서버를 사용하세요.

```powershell
npm test
```

## 조작

- 왼쪽 공정 목록: 웨이퍼 제조 → 산화 → 포토 → 식각 → 증착·이온주입 → 금속배선 → EDS → 패키징
- 드래그 / 방향키: 회전. 휠 / 두 손가락 / +·− 버튼: 확대·축소. Home / ↺: 초기 시점
- 웨이퍼 뷰 / 단면 뷰: 전체 구조와 재료 층 비교
- 재생 / 일시정지, 진행 막대, 재생 속도, 이전·다음 공정
- 재생 버튼을 다시 누르면 일시정지하고, 다시 누르면 멈춘 위치에서 이어서 재생
- 공정을 선택하면 해당 공정의 0%에서 대기하며, 재생은 선택한 공정부터 시작
- 최종 패키징까지 재생한 뒤 정지하며, 재생 버튼으로 현재 공정을 다시 시작

화면의 공정별 참고 링크와 ‘모델 안내 및 출처’에서 공식 자료를 확인할 수 있습니다. 실제 제조에서는 여러 공정이 반복됩니다. 크기·시간·층 두께와 EDS 판정은 학습용 표현이며 실제 제조 레시피나 물리 시뮬레이션이 아닙니다. 패키징은 와이어 본딩의 예시입니다.

## 파일

`index.html` / `styles.css`: 화면과 반응형 레이아웃. `process.js`: 공정 설명·재생 상태. `model.js`: 절차적 3D 모델. `renderer.js`: WebGL·카메라. `app.js`: 화면 제어. `server.mjs`: 루프백 전용 정적 서버.

이 폴더는 정적 웹 호스팅에도 올릴 수 있습니다. 현재 작업은 로컬 파일 생성과 실행만 포함합니다.
